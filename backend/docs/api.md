# API Documentation

Base URL (local dev): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`

---

## `POST /predict`

Takes property specs, returns a price estimate + confidence range + explainability breakdown.

**Request body:**
```json
{
  "city": "bengaluru",
  "locality": "Whitefield",
  "area_sqft": 1250,
  "bhk": 3,
  "bathrooms": 2,
  "floor": 6,
  "total_floors": 14,
  "property_age_years": 3,
  "furnishing_status": "semi",
  "property_type": "apartment",
  "amenities": ["parking", "lift", "security", "power_backup"]
}
```

| Field | Type | Constraints |
|---|---|---|
| `city` | string | must be one of the 12 supported city ids |
| `locality` | string | must belong to `city` |
| `area_sqft` | float | 200–10000 |
| `bhk` | int | 1–6 |
| `bathrooms` | int | 1–8, and ≤ `bhk + 2` |
| `floor` | int | 0–60, and ≤ `total_floors` (unless `property_type` is `plot`) |
| `total_floors` | int | 0–60 |
| `property_age_years` | int | 0–60 |
| `furnishing_status` | enum | `unfurnished` \| `semi` \| `full` |
| `property_type` | enum | `apartment` \| `villa` \| `independent` \| `plot` |
| `amenities` | array of enum | any of `parking, lift, security, power_backup, gym, pool, clubhouse, garden` |

**Response `200`:**
```json
{
  "price": 15125400.0,
  "low": 13858500.0,
  "high": 16392200.0,
  "per_sqft": 12100.3,
  "city_base_rate": 11200,
  "confidence_band_pct": 8.4,
  "model_used": "neural_network",
  "drivers": [
    {"key": "locality", "label": "Locality", "impact_pct": -8.0, "note": "Whitefield vs. city average"},
    {"key": "type", "label": "Property type", "impact_pct": 0.0, "note": "apartment stock"}
  ]
}
```

**Errors:**
- `422 Unprocessable Entity` — validation failure (bad enum value, out-of-range
  number, unknown city/locality, `floor > total_floors`, etc). Body follows
  FastAPI's standard `{"detail": [...]}` shape.
- `503 Service Unavailable` — no trained model found (`ml/models/` is empty —
  run `python train.py` in `ml/` first).

## `GET /compare-models`

Returns evaluation metrics for every trained model, straight from `ml/models/metrics.json`.

**Response `200`:**
```json
{
  "results": {
    "linear_regression": {"rmse": 4124603.0, "mae": 2373370.0, "r2": 0.881, "train_seconds": 0.0},
    "random_forest": {"rmse": 2990915.0, "mae": 1850696.0, "r2": 0.937, "train_seconds": 45.2},
    "xgboost": {"rmse": 2350000.0, "mae": 1400000.0, "r2": 0.958, "train_seconds": 8.4},
    "neural_network": {"rmse": 2339672.0, "mae": 1266877.0, "r2": 0.962, "train_seconds": 42.2}
  },
  "best_model": "neural_network"
}
```

**Errors:** `503` if `ml/models/metrics.json` doesn't exist yet.

## `GET /city-stats`

Average price/sq.ft and metadata per city, from the `city_stats_cache` table
(refreshed by `python seed_db.py`).

**Response `200`:**
```json
[
  {"city": "mumbai", "name": "Mumbai", "state": "Maharashtra", "avg_price_per_sqft": 27850.4,
   "yoy_growth_pct": 8.1, "locality_count": 6, "listing_count": 1467}
]
```

**Errors:** `503` if the cache table is empty — run `python seed_db.py` in `backend/` first.

---

## `GET /price-trends?city={city}`

12-month ₹/sq.ft trend series for the given city (used by the trend line chart).

**Response `200`:**
```json
{
  "city": "bengaluru",
  "points": [
    {"month": "Sep", "rate": 10340},
    {"month": "Oct", "rate": 10410}
  ]
}
```

**Errors:** `404` if `city` isn't one of the 12 supported cities.

## `GET /health`

Liveness/readiness check. `{"status": "ok", "model_loaded": true}`.
